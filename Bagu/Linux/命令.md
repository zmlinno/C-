### `.bashrc`：终端启动时加载的配置

用户的 Bash 配置文件通常是：
```
~/.bashrc
```

它可以保存常用设置，比如别名或环境变量。修改 `.bashrc` 后，可以执行下面的命令，让修改立刻在当前终端生效：
```
source ~/.bashrc
```

之后每次启动交互式 Bash 终端，也会读取这个配置文件。比如，如果你希望每次打开终端都加载 ROS2，可以把这一行写进 `.bashrc`：
```
source /opt/ros/humble/setup.bash
```

### `apt`：安装和管理软件包

`apt` 是 Ubuntu 常用的软件包管理工具。常用命令有：
```
sudo apt update
sudo apt install 软件包名称
sudo apt remove 软件包名称
```
- `apt update`：更新可用软件包的信息，不是升级所有软件。
- `apt install`：安装软件包。
- `apt remove`：卸载软件包。
假如安装git
sudo apt install git
