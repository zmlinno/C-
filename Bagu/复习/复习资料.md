关于 export ROS_DOMAIN_ID=25 是把变量 ROS_DOMAIN_ID的值设置为25
exprot - 让这个变量也能被当前终端启动的程序读取，比如ROS2 节点和命令
在 ROS 2 里，`ROS_DOMAIN_ID` 用来区分不同的通信域。**Domain ID 相同的 ROS 2 节点通常可以互相发现并通信；ID 不同的节点通常互相看不到。**

那么如何查看当前 Domain ID 是否相同呢
echo $ROS_DOMAIN_ID - 如果都显示25,说明这些终端当前设置的 Domain ID相同
printenv ROS_DOMAIN_ID 如果没有任何输出，表示这个终端没有设置该变量，ROS2通常会使用默认值0,主要要在主机终端和Docker容器内部都检查一次

*如果说 主机是25, Docker是24,就表示 Domain ID不同，它们的ROS2节点通常无法互相发现和通信，我们可以在docker里面输入 export ROS_DOMAIN_ID=25 那么docker的Domain ID也会变成25,与主极端一致，*


```
source /opt/ros/humble/setup.bash
```
关于这个命令是 加载ROS2 Humble的环境配置，让当前终端能找到ROS2的命令，库和软件包，通常打开新的终端的话都要运行一次，因为它只对当前终端生效，运行后，这个终端才能使用ROS2 Humble的命令
如果想让 Ubuntu 每次打开终端时自动加载，可以把它加到 `~/.bashrc`：

```
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
```
